# Logo and mascot

| File | What it is |
|---|---|
| `symbol.svg`, `symbol-mono.svg` | The symbol, in colour and in one colour (`currentColor`) |
| `lockup.svg`, `lockup-dark.svg`, `lockup-mono.svg` | Symbol and wordmark for light grounds, dark grounds, and one colour |
| `readme-header-light.svg`, `readme-header-dark.svg` | The README's header |
| `favicon.svg`, `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png` | Icons |
| `social-preview.png`, `social-preview.svg` | The repository's social preview, 1280 by 640 |
| `mascot/` | The mascot, a winking face over a slice of melon, in colour and in one colour |

The colours are flesh `#EF4A5C` and rind `#1C9160`, with `#16191F` lettering on light grounds and
`#F5F2EA` on dark ones. Under about 16 px tall, use the symbol without the wordmark.

The wordmark is Chakra Petch Medium as outlines, so the files need no font. Chakra Petch is under the
SIL Open Font License 1.1. In a terminal the mascot is drawn in half blocks by
`crates/termelon/examples/agent_demo.rs`.
